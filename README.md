# File Action Skill - 证书文件管理技能

这是一个用于 OpenClaw 的技能，帮助大学生和个人管理各类证书、获奖证书、荣誉证书和申报材料。

## 📋 功能特性

- 📄 **智能识别**：自动识别证书类型和内容
- 🏷️ **标签管理**：为文件添加自定义标签
- 📅 **日期提取**：自动识别获奖日期（针对获奖证书）
- 🔍 **快速检索**：通过标签、日期或关键词快速查找文件
- 💾 **安全存储**：所有文件和标签数据持久化存储
- 📊 **报告生成**：生成证书清单和统计报告

## 🚀 快速开始

### 1. 安装技能

```bash
# 克隆或下载技能到本地
git clone <repository-url>
cd certificate-manager

# 设置环境变量
export STORAGE_DIR=/path/to/your/storage/directory
```

### 2. 基本使用

#### 上传和识别证书

当你发送一个证书文件时，系统会：

1. **自动识别**：分析文件内容，识别证书类型
2. **提取信息**：获取获奖人、颁发机构、日期等关键信息
3. **询问确认**：展示识别结果，询问是否正确
4. **存储标签**：确认后将文件和标签一起存储

**示例交互：**

```
用户：[发送证书图片]

系统：我识别到这是一个获奖证书，请确认以下信息是否正确：

📋 **识别结果：**
- 证书类型：获奖证书
- 获奖人：张三
- 颁发机构：XX大学
- 奖项名称：优秀学生奖学金
- 获奖日期：2024年5月15日

请回复"正确"确认保存，或告诉我需要修改的内容。

用户：正确

系统：✅ 已保存！
标签：获奖证书、张三、XX大学、2024年5月15日、优秀学生奖学金
```

#### 查询和检索文件

**按标签查询：**
```
用户：找一下我的获奖证书

系统：找到 2 个相关证书：
1. 优秀学生奖学金证书

   日期：2024-05-15

2. 数学竞赛一等奖证书

```

**按日期查询：**
```

2. 英语六级证书 - 2024-06
```

**按颁发机构查询：**
```
用户：XX大学颁发的证书有哪些？

系统：XX大学颁发的证书：
1. 优秀学生奖学金证书 - 2024-05-15
2. 毕业证书 - 2024-06
```

## 📁 存储结构

技能使用以下目录结构存储文件：

```
$STORAGE_DIR/
├── files/                    # 原始文件存储
│   ├── 2024/
│   │   ├── 05/
│   │   │   ├── 优秀学生奖学金证书.jpg
│   │   │   └── ...
│   │   └── ...
│   └── ...
├── metadata/                 # 元数据存储
│   ├── files.json           # 文件索引
│   ├── tags.json            # 标签索引
│   └── dates.json           # 日期索引
└── config.json              # 配置文件
```

## 🔧 命令行工具

技能提供了命令行工具来管理证书：

### 处理证书

```bash
python scripts/process_file.py --storage-dir /path/to/storage upload certificate.jpg --text "证书内容..."
```

### 搜索证书

```bash
# 按标签搜索
python scripts/process_file.py --storage-dir /path/to/storage search "获奖证书" --type tag

# 按年份搜索
python scripts/process_file.py --storage-dir /path/to/storage search "2024" --type year

# 按关键词搜索
python scripts/process_file.py --storage-dir /path/to/storage search "奖学金" --type keyword
```

### 列出标签

```bash
python scripts/process_file.py --storage-dir /path/to/storage tags
```

### 生成报告

```bash
python scripts/process_file.py --storage-dir /path/to/storage report --year 2024
```

## 🏷️ 证书类型

技能支持识别以下类型的证书：

| 类型 | 关键词 |
|------|--------|
| 获奖证书 | 获奖、奖励、奖项、奖学金、一等奖、二等奖、三等奖、优秀、竞赛 |
| 荣誉证书 | 荣誉、称号、表彰、先进、模范 |
| 资格证书 | 资格、认证、证书、执照、许可证 |
| 申报材料 | 申报、申请、材料、项目、计划 |
| 毕业证书 | 毕业、学位、学士、硕士、博士 |
| 结业证书 | 结业、培训、进修 |

## 🔍 识别规则

### 日期识别

技能会自动识别以下格式的日期：

- 2024年5月15日
- 2024年5月
- 2024.5.15
- 2024-05-15
- 2024/05/15

### 信息提取

- **获奖人**：从证书中提取获奖人姓名
- **颁发机构**：识别颁发证书的大学、学院、公司等
- **奖项名称**：提取具体的奖项或荣誉名称
- **证书编号**：识别证书的唯一编号

## ⚠️ 注意事项

1. **文件格式支持**：支持 JPG、PNG、PDF 等常见格式
2. **识别准确性**：AI 识别可能不完全准确，请仔细确认识别结果
3. **存储空间**：建议定期清理不需要的文件
4. **隐私保护**：所有数据存储在本地，不会上传到云端

## 🛠️ 故障排除

### 识别不准确

如果识别结果不准确，请手动提供正确信息，系统会学习并改进识别算法。

### 文件找不到

检查标签是否正确，或尝试使用不同的关键词搜索。

### 存储空间不足

清理不需要的文件或扩展存储目录。
