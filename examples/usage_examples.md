# File Action Skill - 使用示例

本文件展示了 File Action Skill 的各种使用场景和交互示例。

## 📋 示例 1：上传和识别获奖证书

### 用户操作
```
用户：[发送证书图片]
```

### 系统响应
```
系统：我识别到这是一个获奖证书，请确认以下信息是否正确：

- 颁发机构：XX大学
- 奖项名称：优秀学生奖学金
- 获奖日期：2024年5月15日
- 证书编号：XXU20240515001

**置信度：** 92.5%

**建议标签：** 获奖证书、张三、XX大学、2024-05-15、优秀学生奖学金

请回复"正确"确认保存，或告诉我需要修改的内容。
```

### 用户确认
```
用户：正确
```

### 系统保存
```
系统：✅ 已保存！

📁 **文件信息：**
- 文件名：优秀学生奖学金证书.jpg
- 存储位置：files/2024/05/优秀学生奖学金证书.jpg
- 文件ID：file_001

🏷️ **标签：** 获奖证书、张三、XX大学、2024-05-15、优秀学生奖学金

```

## 💡 使用技巧

1. **自然语言交互**：可以直接用自然语言描述需求，系统会自动识别意图
2. **多条件搜索**：可以组合多个条件搜索，如"2024年XX大学的获奖证书"
3. **批量操作**：支持批量导入、批量删除、批量添加标签
4. **智能识别**：系统会学习用户的纠正，提高识别准确率
5. **快速访问**：常用证书可以添加"重要"标签，方便快速查找

## 📞 常见问题

**Q: 识别不准确怎么办？**
A: 在确认步骤中手动纠正，系统会记录并改进识别算法。

**Q: 如何快速找到某个证书？**
A: 使用标签、年份、颁发机构或关键词搜索，系统支持模糊匹配。

**Q: 支持哪些文件格式？**
A: 支持 JPG、PNG、PDF、DOC、DOCX 等常见格式。

**Q: 数据安全吗？**
A: 所有数据存储在本地，不会上传到云端，支持加密备份。
